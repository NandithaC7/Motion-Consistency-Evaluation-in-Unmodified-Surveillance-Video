# Project website

Editorial documentation site for **Motion Consistency Evaluation in Unmodified Surveillance Video Data**.

## Stack

- Next.js (App Router)
- React
- Tailwind CSS
- Framer Motion
- Recharts
- Lucide Icons

## Pages

| Route   | Purpose                                      |
| ------- | -------------------------------------------- |
| `/`     | Home — hero, mock upload, pipeline, overview |
| `/about`| Model, specifications, method                |
| `/results` | Placeholder metrics and charts            |
| `/docx` | University documentation portal              |

## Develop

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Production

```bash
npm run build
npm start
```
